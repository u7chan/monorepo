# コストマスタの更新

`projects/cost-master` のマスタ（`prices.json` / `enabled.json`）を更新する。正本は
[README.md](../../../README.md)（取り込み・マスタのメンテ）と [docs/adr/0000-read-only-master-service.md](../../../docs/adr/0000-read-only-master-service.md)（判断の理由）。

## 前提

- マスタは `MASTER_DIR`（コンテナでは volume）にあり、**スイッチかアップロードで即時反映**される。image の再ビルドは要らない
- 価格は機械生成、判断は人の意思。**混ぜない**（`prices.json` を手で編集しない）
- 直前の内容は `<kind>.json.bak` に 1 世代だけ残る。スイッチもこの `.bak` を更新するので、戻す用のファイルは先にダウンロードする

## 価格を更新する

1. `bun run generate -- --dry-run` で件数と差分を出す（`+` 追加 / `-` 削除 / `~` 単価変更）
   - サマリには画像と音声の件数が出る。音声の行は `input_text` / `output_audio` を持ち、`入力` のバッジが付く
2. 差分が意図どおりか読む。心当たりのない大量の `-` や 0 行化があれば、上流の障害を疑って 1 に戻る
3. `bun run generate` で `src/server/data/prices.json` を更新する
4. 画面（`/`）の「マスタの更新」で種類 `prices.json` を選び、そのファイルをアップロードする
5. `/api/health` の `version` と `masterFetchedAt` が進んだことを確認する
6. `/api/models` の行数と `kind` の内訳（画像 / 音声）が生成物と合っていることを確かめる

`version` は**行が変わったときだけ**進む。変わっていないのに進んでいたら差分を疑う。

## 語彙（スキーマ）が変わるリリース

行に `kind` を足したときのように、マスタの形が変わる版をデプロイすると、volume に残っている旧形式の
ファイルは 1 行も読めず、`failure: prices-no-usable-rows` の 503 が続く。**アップロードを先、デプロイを
後**にする（逆順にすると、デプロイからアップロードまでの間だけ画面と u7agent が 503 になる。データは消えない）。

1. 新しい版で `prices.json` を生成する（`bun run generate`）
2. **先に**画面からアップロードする。旧版は知らないキーを無視するので、反映しても旧版は読める
3. `/api/health` が `ok: true` で、行数と `kind` の内訳が生成物と合っているのを確かめる
4. そのあとで新しい image をデプロイし、もう一度 3 を確かめる

アップロード前に新しい版をデプロイしてしまった場合は、`/api/health` の `failure` を見てから
新しい `prices.json` をアップロードすれば直る（`prices-missing` なら置き場の `MASTER_DIR` を疑う）。

## 判断を更新する

1 モデルだけなら画面のスイッチで切り替える。一括で変えるときと、メモを書くときはファイルを使う。

1. 画面（`/`）の一覧でスイッチを切り替える。行が無いモデルは「一覧に出す」が既定
2. 行を足す・`note` を書く・一括で変えるときは、「マスタの更新」で `enabled.json` をダウンロードする
   ```json
   { "models": [{ "modelId": "vendor/model", "enabled": false, "note": "理由を 1 行" }] }
   ```
3. アップロードする。同じ `modelId` を `enabled` 違いで 2 回書くと拒否される（全体が反映されない）
4. 画面のスイッチが「一覧に出さない」になったことを確認する。**`/api/health` の `version` / `masterFetchedAt` は
   動かない**（あれは `prices.json` の値だけ）
5. u7agent の一覧は、その画面で [カタログ更新] を押すまで変わらない

## 失敗したとき

画面に固定文言で理由が出る。ファイルは変わっていない。

- `JSON として読めません` … 構文エラー。ダウンロードし直して編集する
- `内容に不正な行があります` … 型・語彙・重複・`enabled` の食い違い。1 行でも不正なら全体を拒否する
- `現在の enabled.json に不正な行があります` … スイッチの更新。ダウンロードして直し、アップロードし直す
- `置き換えるとマスタを読めなくなる` … もう片方のファイルが壊れている。先にそちらを直す
- `ファイルが大きすぎます` … 1 MiB を超えている。`prices.json` なら生成し直す

## 戻す

同じ画面で `<kind>.json.bak`（1 世代前）をアップロードするか、直前にダウンロードしたファイルを
アップロードし直す。**コンテナや image tag を戻してもマスタは戻らない。**

## やらないこと

- `prices.json` の手編集（生成の結果を上書きしない）
- 価格を根拠にした生成の拒否（表示だけを変える）
- 指示なしのマージ・デプロイ（デプロイ手順はこのリポジトリに無い）
