# 0000. read-only のコストマスタを別サービスにする

- 状態: 採用
- 日付: 2026-11-16

## 背景

u7agent の設定 → コンテンツ生成はモデル名しか出さず、1 枚 $0.007 のモデルと $0.25 のモデルが同じ見た目で並ぶ。
価格は OpenRouter のモデルごとの `/endpoints` の `pricing[]` にしか無く、一覧 API は返さない。

BFF が価格を取りに行くと、設定画面の更新がモデル数ぶんの上流リクエストに縛られる（2026-11-16 時点で 68 件）。
加えて「高価だから既定で一覧に出さない」という人の判断をどこかに持つ必要があり、リポジトリの seed だと
変更のたびに PR が要る。

## 決定

### 別サービスにする

価格と判断を u7agent の外に置く。u7agent は任意の URL に問い合わせ、未設定または OFF なら何も変わらない。
判断の変更が u7agent のリリースと独立し、u7agent 側のロールバックも設定 1 つで済む。

### read-only にする（DB・認証を持たない）

読み取りの API だけを公開し、DB も認証も持たない。LAN / VPN の内側に置く前提も変えない。
マスタの更新は当初「ファイルを編集してデプロイ」で足りるとしたが、**この判断は改訂した**（下の「改訂」）。

### マスタを 2 ファイルに分ける

`prices.json` は機械生成、`enabled.json` は人手。1 ファイルに混ぜると、生成スクリプトが人の判断を
上書きするか、人が生成値に触れるかのどちらかになる。生成は行だけを書き、判断は別ファイルに置く。

### `enabled` の既定を true にする

判断が無いモデルは一覧に出す。隠す判断だけを明示させることで、新しいモデルが黙って消えない。
同じモデルの `enabled` が食い違う行は両方落とし、既定へ倒す（隠す判断を誤って適用する方が害が大きい）。

### 同じ請求単位は最大単価に潰す

上流は 1 モデルに複数 endpoint を返すことがある（2026-11-16 時点で 5 件、うち 2 件は同じ請求単位で単価が
違う。最大 2 倍差）。配列順に依存させず、過小評価しない側に倒す。`endpoint` は応答に含めない
（OpenRouter 固有の語彙を u7agent まで持ち込まない）。

### 通貨は USD 固定で付与する

上流の `pricing[]` は通貨を宣言しない（2026-11-16 時点で全行に無い）。マスタは `USD` を付与し、
将来 `USD` 以外を宣言する provider を足したときにその行を落とす。

### マスタの置き場は volume にし、画面から置き換える（改訂）

当初はマスタを image に焼き込み、更新のたびに CD とデプロイを回す構成にした。しかし「判断はリリースを
待たずに変えたい」という出発点に対して、判断 1 件の変更にも image の再ビルドが必要になり、目的を満たして
いなかった。

そこでマスタを `MASTER_DIR`（volume）に移し、`GET /api/master/{prices,enabled}` でダウンロード、
`PUT /api/master/{prices,enabled}` で置き換える。リクエストごとに mtime を見て読み直すので再起動は要らない。

- **認証は持たない。** 守るのは「一覧に出すか」という表示だけの情報で、秘密も会計も無い。統制は到達範囲
  （LAN / VPN）と same-origin 検査（別サイトからの送信を拒否）に置く
- **置き換えは原子的**（tmp + rename）で、直前の内容を 1 世代 `.bak` に残す
- **アップロードは起動時の読み込みより厳しい**（1 行でも不正なら全体を拒否）。人が明示的に反映する操作で、
  黙って行を落とすと「隠したつもりが隠れていない」に気付けない
- **片方だけ差し替えて全体が読めなくなるなら拒否する**（「反映したのに 503」を作らない）
- サーバーは上流へ出ない。価格の取り込みは手元で実行し、結果をアップロードする

これにより、切り戻しの意味は「image tag を戻す」から「`.bak` または直前のファイルをアップロードし直す」に
変わる。tag を戻してもマスタは戻らない。

### ファイルが読めないときは 503 にする

空の一覧を 200 で返すと「価格が消えた」と読める。読めないときは失敗として返し、u7agent に前回の
値を維持させる。`/api/health` も `ok: false` で知らせる。

判定はファイル単位と行単位で分ける。

- **ファイル単位**: `prices.json` と `enabled.json` のどちらも、無い・トップレベルの形が違う・JSON として
  壊れているときは 503。`enabled.json` を落とすと判断が 1 件も適用されず「全部表示」が配信され、
  隠したつもりのモデルが黙って戻る。
- **行単位**: 型・語彙・負の単価・重複・同じモデルの `enabled` の食い違いは、その行だけ落として
  既定（表示する）へ倒し、起動ログに理由を出す。1 行の破損で価格一覧全体を止めない。

## 影響

- u7agent は価格の取得先を 1 つの URL として持ち、未設定・OFF・失敗のどれでも従来どおり動く。
- 価格の鮮度は `fetchedAt` で見える。自動更新はしないので、古い価格が残る期間は許容する。
- token 建てのモデルは 1 枚単価を出さない（1M token あたりで出す）。1 枚の実額は測らない。
- マスタは git の履歴から外れる（volume が正）。変更の記録は `.bak` と画面の操作だけになるため、
  「いつ何を隠したか」を残したい場合は監査ログを足す（この版では持たない）。
