maimai でらっくすNET スコア抽出ブックマークレット

「レコード → 楽曲スコア」の一覧ページ（LEVEL / バージョン別）で実行すると、 各譜面のスコアを JSON ファイルとしてダウンロードするブックマークレットです。 譜面難易度（BASIC〜Re:MASTER）と ST/DX はページ上の画像から判別して JSON に含めます。 （ログイン: maimai でらっくすNET）

インストール

  1. 下のリンクをブックマークバーへドラッグ（または右クリック → ブックマークに追加）
  2. maimai でらっくすNET にログインし、一覧ページ（例: LEVEL 13 のページ）を開く
  3. ブックマークをクリック → maimai_level19_YYYY-MM-DD.json のような JSON がダウンロードされる

maimai スコア抽出

このボタンはクリックするものではありません。ドラッグしてブックマークバーへ追加し、 maimaiNET の一覧ページを開いた状態でそのブックマークをクリックして使います （このページ上でクリックしても何も起きません）。

※ ドラッグができない環境（モバイル等）では、下のコードをコピーして 「ブックマークの編集 → URL 欄に貼り付け」でも登録できます。

コード（コピー用）

出力 JSON の形式

{
  "source": "https://maimaidx.jp/maimai-mobile/record/musicLevel/search/?level=23",
  "page": { "level": "23", "version": null, "diff": null },
  "entries": [
    { "song": "曲名", "level": "15", "difficulty": "Re:MASTER",
      "system": "DX", "achievement": 98.7654,
      "perfect": 1234, "total": 1345,
      "idx": "楽曲詳細ページのトークン（将来用）" }
  ]
}
  • achievement: null のエントリは「未プレイの曲」（スコア表示が無い）
  • level は表示 Lv のテキスト（例: 13+）

取り込み（WSL 側）

ダウンロードした JSON を WSL の任意の場所（例: /tmp/）に置き、 当プロジェクトの poc/run.py に渡すだけで計算できます（拡張子・内容で自動判定）。

cd projects/_labs/maimai_dx_rating_calc
cp /mnt/c/Users/<ユーザー名>/Downloads/maimai_level19_*.json /tmp/
python3 poc/run.py /tmp/maimai_level19_2026-08-31.json /tmp/rating_out --constants data/maimai_constants.json

ファイルをエージェント（Pi 等）に渡す場合も、パスを伝えるだけで中身を貼り付ける必要はありません。

注意

  • 一覧ページ以外（楽曲詳細ページ等）で実行すると譜面エントリが無く、警告ダイアログが出ます
  • ダウンロードした JSON は実スコアを含む個人データです。取り扱いに注意し、Git には入れないでください（当プロジェクトでは data/ 配下が git 除外済み）
  • 出力には idx（楽曲詳細ページのトークン）が含まれます。取り扱いは自己責任でお願いします
