# ADR 0013: 使用不可と残りわずかの印を文字の記号から SVG にする

- Status: accepted
- Date: 2026-10-28
- 追記: [ADR 0009](0009-window-blocking-and-five-hour-rolling.md) の停止表示の見た目

## 背景

ゲージの「使用不可」と「残りわずか」は、どちらも ▲ を先頭に置いていた。文字の記号はフォントに依存し、
小さなサイズでは線が細い。色が見分けにくい環境では「止まっている」と「注意」の区別を形から読み取りにくく、
見出しの状態ラベルにある ▲ とも紛らわしい。

## 決定

- ゲージの「使用不可」は円に斜線を引いた禁止アイコン、「残りわずか」は感嘆符付きの警告三角をインライン SVG で描く。
- SVG は `currentColor` で文字色に追従させ、`aria-hidden` にする。意味は隣の「使用不可」「残り 15%」が伝える。
- 色はこれまでどおり赤（danger）と橙（attention）を併用し、形だけに頼らない。
- 見出しの状態ラベルの記号（● ○ ▲ ■）は変えない。ゲージの印とは役割が違い、文字も小さいため。

採用しない案:

- 絵文字（🚫 / ⚠️）: OS ごとに形と色が変わり、テーマの色に追従しない。
- アイコンライブラリ: 2 つの図形のために依存を増やさない（[0000](0000-stack-and-style.md)）。
- 文字の ▲ を大きくする: フォント依存のままで、禁止と注意の区別も付かない。

## 理由

停止と注意は、色だけでなく形でも区別できる必要がある。インライン SVG なら追加の取得も依存もなく、
文字色に追従してライト / ダークの両方で読める。読み上げは既存の文言に任せ、装飾として扱う。

## 影響

- `UsageMeter` の先頭の記号が SVG になる。`up-meter-value` はアイコンと文言を横に並べる。
- 状態ラベルの記号は文字のままで、テストの期待値も変わらない。
