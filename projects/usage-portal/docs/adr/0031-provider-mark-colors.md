# ADR 0031: provider のマークにブランド色を付け、使えないときだけ灰色にする

- Status: accepted
- Date: 2026-11-23
- 一部置き換え: [ADR 0027](0027-provider-order-and-icons.md) と [ADR 0030](0030-provider-marks-from-hwc.md) の、
  マークを `currentColor` の 1 色のままにする決定

## 背景

ADR 0027 と ADR 0030 は、マークを 1 色（`currentColor`）にして状態ラベルの色と競合させないことにした。
実際に使うと、カードが 3 枚並んだとき、どれも同じ灰色の枠に同じ灰色のマークが入る。形を読み取らないと
provider が分からず、形の違いが小さい Claude と Codex は特に見分けにくい。同じ利用者が使う HWC は同じマークを
ブランド色で塗っており、同じ provider が画面ごとに違う色で見える。

一方、契約が切れたアカウントや枠を使い切ったアカウントは、色を付けても「いま使える」とは読めない。

## 決定

- マークの色を HWC のブランド色に合わせる。Claude `#c15f3c`、Codex `#000000`、OpenCode `#1f1f1f`。
  暗い地では HWC と同じく Claude `#e08a68`、Codex `#ffffff`、OpenCode `#eeeeee` にする。
  OpenCode の内側のシェードも HWC と同じ 0.2（暗い地は 0.28）にする。
- 色を当てるのは、カード見出しのマークと、`⋮` の「ステータス」の項目のマーク。
- カードのマークは、契約が無い（未接続）・契約が切れた（契約エラー）・枠を使い切った（上限到達）ときだけ
  `--up-muted` の灰色にする。それ以外は色を残す。
- 判定は状態ラベルと同じ `deriveProviderStatus` に持たせ、戻り値の `mark` だけを見る。ラベルの文字列で
  分岐しない。文言を変えたときに色が付かなくなるため。

採用しない案:

- すべてのカードを常にブランド色にする: 使えないカードも使えるカードと同じ色で並び、一覧から
  「いま使えるのはどれか」が読めなくなる。ADR 0016 で末尾に回している意味も薄れる。
- `tone` で色を決める: 残りわずか・更新停止・再サインインも `attention` で、契約の有無と一致しない。
- 枠や地もブランド色にする: カードの中に面の色が増え、状態ラベルの枠と見分けが付かなくなる。
- 未接続・取得エラーでも色を落とす: 取得エラーは契約の有無と別の軸で、色を落とすと契約が無いと読み違える。

## 理由

マークは「どの provider か」を示す記号で、状態ラベルが「いま使えるか」を示す。色をこの 2 つの軸に分ければ、
provider は形と色の 2 つで分かり、使えないカードだけが灰色になって一覧の中で目立たない。
灰色はこれまでどおり `--up-muted` を使うので、使えないカードの見た目は今までと変わらない。

## 影響

- `src/client/lib/status.ts` の `ProviderStatus` に `mark` が増え、`test/client-status.test.ts` の期待値が変わる。
- `src/client/lib/provider-icon.ts` の `parts` は `opacity` ではなく `shade` を持つ。値は CSS 変数で決める。
- `src/client/components/ProviderIcon.tsx`、`ProviderCard.tsx`、`src/client/styles.css` の
  `--up-mark-*` とマークの色の規則が変わる。
- 明るい地で Codex と OpenCode のマークは黒、暗い地では白になる。Claude は明暗で橙の濃さが変わる。
- メニューの項目のマークは常に色付きになる。
