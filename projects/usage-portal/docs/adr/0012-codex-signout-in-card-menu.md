# ADR 0012: Codex のサインアウトをカードのメニューへ移し、サインインはカードに残す

- Status: accepted
- Date: 2026-10-28
- 一部置き換え: [ADR 0017](0017-probe-prompts.md) の追記（設定をカードのメニューへ移したため、メニューはサインアウト以外でも描く）

## 背景

Codex カードには「サインイン済み」と「サインアウト」が常に出ていた。日常の操作は利用枠を見るだけで、
サインアウトはたまにしか使わない。OpenCode Go のカードは編集と削除を `⋮` に逃がしており（[0010](0010-menu-and-modal-layout.md)）、
同じ画面で Codex だけ常設ボタンが残っていた。

一方、未接続と再サインインのときの「Sign in with ChatGPT」は、カードの中身が空になる状態で唯一の復帰手段になる。

## 決定

- Codex カード右上の `⋮` に「サインアウト」を入れる。メニューはサインアウトを出せる状態のときだけ描く。
- サインインの開始ボタンはカードの中に残す。未接続・再サインイン・失敗・中断のときだけ出る。
- 進行中のサインイン（コード、URL、方式の選択、中断）はこれまでどおりカードの中に出す。
- サインイン済みで進行中の操作も通知も無いときは、「Codex の接続」セクションごと出さない。
- サインアウトに失敗したときのメッセージは、カードの中に出す。

採用しない案:

- サインインも `⋮` に入れる: 未接続のカードはゲージも推移も無く、隠すと押す場所が無くなる（[0010](0010-menu-and-modal-layout.md) の案内カードと同じ理由）。
- サインイン済みでも接続セクションを出す: 見出しと「サインイン済み」だけが残り、操作の無い領域が増える。
- サインアウトをヘッダーのメニューに置く: 全体の操作と接続ごとの操作が混ざる。対象はカードの中に閉じる。

## 理由

サインアウトは資格情報を持つ状態でだけ使える設定操作なので、カードの `⋮` に置くと対象が明確になる。
サインインは復帰の入口で、未接続のときのカードは空になる。押せる場所を隠すと、何をすればよいか分からない。

## 影響

- Codex カードの描画は `CodexCard` に分かれ、`ProviderCard` は provider 共通の骨格だけを持つ。
- サインアウトの可否は `showsSignOutButton` のまま。カードのメニューはこの判定に従う。
- サインイン済みで通知が無いとき、カードの高さが接続セクションの分だけ縮む。
